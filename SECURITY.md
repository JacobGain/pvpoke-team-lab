# Security policy

## Supported versions

Security fixes are applied to the current production release and prepared on
the `staging` branch before release.

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/JacobGain/pvpoke-team-lab/security/advisories/new).
Include the affected page or component, reproduction steps, impact, and any
suggested mitigation. Do not include sensitive vulnerability details in a
public issue.

TeamLab stores inventory and saved teams in the user's browser. It does not
send that data to TeamLab or a third-party application service. Reports about
unexpected network transmission or access to browser-stored data are in scope.
