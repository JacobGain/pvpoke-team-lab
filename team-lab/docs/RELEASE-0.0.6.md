# Release v0.0.6

## PvPoke data refresh
- Refreshed bundled Pokémon, move, ranking, and meta data from the current PvPoke source.
- Updated the battle engine and local artwork to keep TeamLab aligned with upstream gameplay changes.
- Normalized PvPoke sentinel values so missing data remains valid and consistent in TeamLab.

## Mega and battle updates
- Added support for Mega levels and the related CP and damage changes in the upstream data model.
- Updated form and move data for newly supported Mega Pokémon and training-battle move sets.
