# PvPoke Battle and Team Builder Deep Links

> **Phase:** Phase 6 — Team Analysis  
> **Status:** Complete for the Open Great League MVP  
> **Route:** `/teams/:teamId/simulate`  
> **Last reviewed:** 2026-07-25

## Summary

Every completed saved-team matrix now exposes:

- one PvPoke Team Builder link containing the three exact selected inventory
  builds;
- one PvPoke Single Battle link for every measured matrix matchup.

The links open in a new tab and preserve the build and shield assumptions
behind the TeamLab run. They are an escape hatch into upstream analysis, not a
second source of TeamLab state.

## Upstream characterization

The serializer follows the formats generated by the inherited source:

| Upstream source | Characterized behavior |
| --- | --- |
| `src/js/pokemon/Pokemon.js` | Serializes custom level, IVs, battle settings, Shadow state, and move strings |
| `src/js/interface/PokeMultiSelect.js` | Joins Team Builder Pokémon with commas |
| `src/js/interface/TeamInterface.js` | Builds `team-builder/{cup}/{cp}/{encoded-team}` |
| `src/js/interface/Interface.js` | Builds `battle/{cp}/{p1}/{p2}/{shields}/{m1}/{m2}/` |
| `src/.htaccess` | Defines the accepted Team Builder and Single Battle path routes |

TeamLab owns a small typed implementation of that public URL contract. It does
not call the upstream interface objects or mutate their browser globals.

## Exact custom build format

TeamLab always serializes explicit custom stats:

```text
species-level-attackIV-defenseIV-hpIV-4-4-1-1
```

The two `4` values represent neutral starting Attack and Defense stages in
PvPoke’s offset URL format. The final `1-1` preserves shield-baiting and
optimized-move-timing defaults used by these links.

Move strings use hard move IDs:

```text
FAST_MOVE-CHARGED_MOVE_1-CHARGED_MOVE_2
```

If a build has one charged move, the final value is `0`. Hard IDs avoid
depending on movepool index order when upstream data changes.

Shadow forms whose species ID already ends in `_shadow` are not given a second
Shadow suffix. The serializer can still append PvPoke’s `-shadow` modifier for
an exact build whose Shadow state is not encoded in its species ID.

## Team Builder link

Shape:

```text
{site}/team-builder/all/1500/{encoded exact builds}
```

The three builds come from the request that actually produced the completed
matrix. This means:

- lead, switch, and closer order is retained;
- current versus planned selection has already been resolved;
- exact level, IVs, and entered moves are retained;
- the link cannot silently change when form controls change after a run.

The URL uses `all` and `1500`, matching TeamLab’s initial Open Great League
scope.

## Single Battle links

Shape:

```text
{site}/battle/1500/{exact team build}/{exact target build}/{shields}/{team moves}/{target moves}/
```

Each link uses:

- the exact owned or planned team member from that matrix column;
- the exact PvPoke-default target that was simulated;
- team and target shield counts from the completed run;
- explicit hard move IDs for both builds.

The link appears alongside the measured matrix evidence. It does not appear on
static alternative cards because those alternatives have not yet been run as
exact substitutions.

## Configuration

`VITE_PVPOKE_BASE_URL` controls both upstream data access and the UI-link base:

```dotenv
VITE_PVPOKE_BASE_URL=/pvpoke/src
```

If omitted, TeamLab uses `/pvpoke/src`. The default works through the existing
Vite `/pvpoke` proxy during local development.

## Run provenance

`SavedTeamRankerRun` now retains the exact `TeamRankerRequest` passed to the
adapter. The field is optional for compatibility with historical fixtures, but
the application service always supplies it.

Link generation happens only when that request is present. This ensures links
describe completed-run evidence instead of rebuilding assumptions from current
UI state.

## Known limitations

- The serializer targets the current upstream URL grammar and needs
  re-characterization if PvPoke changes that grammar.
- Links currently target only Open Great League at 1,500 CP.
- Starting HP, energy, stat buffs, and sandbox actions are not configurable.
- The Team Builder does not encode TeamLab’s lead/switch/closer labels; only
  list order is preserved.
- A PvPoke page may calculate additional upstream scorecard evidence under its
  own current settings and dataset.
- Static owned/unowned alternatives do not receive battle links until an exact
  substitution simulation exists.
