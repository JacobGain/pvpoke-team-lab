# 1.2.0 — What-if team changes

TeamLab 1.2.0 adds an exact what-if workflow to saved-team simulation. Replace
one position with an eligible owned build, compare coverage, scorecard, and
threat matchups against the same targets and shield settings, then update the
original team or save a separately named copy.

The release continues to support Open Great, Ultra, and Master Leagues,
including their Mega formats. Wrangler and its Miniflare dependency were
updated so the locked `undici` version includes the security fixes in 7.29.1.
