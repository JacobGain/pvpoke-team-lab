# Release v1.2.2

## Matchup-backed build planning
- Compare a current or planned build with temporary IV and move candidates against selected ranked threats using exact PvPoke one-on-one simulations.
- Choose shield counts independently, then inspect win/loss/tie, battle rating, remaining HP, energy, and shields for each matchup.
- Alternate IV spreads are treated as different specimens, fitted to the active league's cap, and never overwrite owned Pokémon.
- Results include the PvPoke data version and remain scoped to the selected builds and shield scenario; they are not a team score or a full-team battle prediction.
