# 1.0.0 — First official release

TeamLab 1.0.0 is the first official public release. It provides a local-first
workspace for planning Pokémon GO PvP inventory and teams across Great, Ultra,
and Master League.

- Uses Season 28, Twilight Trails, as the active season with synchronized
  PvPoke rankings, moves, meta opponents, and battle behavior.
- Supports exact and planned inventory builds, IV analysis, saved teams,
  recommendations, simulations, backups, and league-specific persistence.
- Presents a responsive, user-oriented interface for desktop and mobile while
  keeping maintainer diagnostics out of the public build.
- Includes local artwork for battle-relevant alternate forms, including
  Crowned Zacian and Zamazenta, fused Necrozma, Armored Mewtwo, Genesect drives,
  Burmy cloaks, and Sunshine Cherrim.
- Publishes versioned release metadata and a deployment-neutral Cloudflare
  Pages artifact with security headers and automated production checks.

Existing inventory, saved teams, and backups remain compatible with 1.0.0.
