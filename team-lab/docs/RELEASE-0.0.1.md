# Release v0.0.1

## The first TeamLab workspace
- Introduced a local-first Pokémon GO PvP planning app built around Open Great League rankings and battle data.
- Added a validated inventory for current and planned Pokémon builds, including CP, IVs, moves, and build analysis.
- Added ordered saved teams, exact team simulations, matchup scorecards, and anchor-based team recommendations.
- Added portable JSON backup and restore for the user's local collection.

## Responsive player workflows
- Established mobile and desktop layouts for the catalog, inventory, teams, simulation, and recommendation workflows.
- Added accessible form controls, actionable dashboard summaries, and local Pokémon artwork.
